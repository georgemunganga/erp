# P35 private normal-cookie control plane

This tool-only source extends the accepted private P35 internal contract-review cohort. It requires a new, exclusive `proc_p35_http_contract_review_*` database and the real P35 native policy, contract, rate, Submit, Return, correction, resubmission and Approve graph before opening a normal local-auth listener. The existing native API and independent owner evidence remain separate.

The current actors are synthetic workerless Core accounts. The configuration maker and independent configuration reviewer publish the typed review policy. The contract owner is the buyer; a distinct Core approver owns the review assignment and decision. The ungranted account remains a negative control. The private control plane activates only original unused placeholder credentials by compare-and-set, exposes them in a new protected `0600` fixture, and starts a loopback normal local-auth host. A private subject header must return `401` without a session cookie.

The browser fixture records the current tenant, company, branch, buyer, reviewer, supplier, native contract and review identifiers, plus a challenge, expiry and private completion path. Completion merely closes the bounded listener. It is not browser acceptance or an owner claim. A later real browser and separate read-only owner verifier must prove the extra cookie-authenticated commands, original-key recovery, current Core assignments, saved review rows, audit and outbox effects. This slice does not sign or activate a contract, post Finance, send a supplier message or deploy to production.

The flag `P35_HTTP_SERVE_CONTRACT_REVIEW_NORMAL_COOKIE=1` requires the P35 native flag, principal PO source flag, exact fresh P35 database name and no other optional cookie/receiving/invoice/RFQ/return/negative profile. The P35 feature stays off without explicit private configuration and physical readiness. The control-plane code checks the registered concrete provider without executing actor-scoped readiness from a root dependency-injection scope; authenticated browser HTTP must supply that proof later.
