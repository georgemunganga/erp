# Procurement workflow reference trace

> **27 October 2026:** This reference preserves the original external journey mapping. Its dated implementation column is historical; the [current UAT and gap register](gap-closure/PROCUREMENT-UAT-AND-GAPS-20261027.md) records what is implemented and which tests remain.

**Status:** implementation reference, 18 October 2026. **Scope:** functional workflow coverage, not adopted business policy or copied product code.

Zoho Procurement's [help index](https://www.zoho.com/ca/procurement/help/getting-started/welcome/) is the primary checklist for the journeys users should be able to complete. Its product-specific labels, screens, payment implementation and defaults are not our implementation contract. The 28-section `PROC-*` feature specifications define our transitions and controls; the [live roadmap](PROC-ROADMAP-LIVE-BUILD.md) records what is actually implemented. [ERPNext's procurement cycle](https://docs.frappe.io/erpnext/procurement-cycle-overview) is a secondary check when a data or implementation detail needs another public example.

## Acceptance rule for a referenced workflow

For each row, implement and verify the full operation: entry and actor; state transition; permission plus record scope; business guard; data owner; source/target links; audit and version; failure/retry; loading/empty/error/denied UI states; and Playwright plus API tests for allowed and denied paths. Record exact source behavior used as inspiration in the child specification when it affects a decision. Do not infer business authority or approval thresholds from a vendor's defaults.

**Next vertical slice:** PROC-02/03 approved request-line conversion. It is the bridge between the live own-request draft and RFx/PO drafts. Define a stable allocation record per source line, route type and quantity/value; prevent exceeding approved residual; allow bulk conversion across approved requests without losing line provenance; check policy/budget/supplier eligibility and actor scope server-side; make retry and cancellation release explicit. Until approval and Finance commitment contracts exist, the UI may present conversion as a gated workflow only.
