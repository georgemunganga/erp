# P32 private commercial Draft HTTP proof — first bounded phase

This opt-in tool phase uses a **fresh** `proc_p32_http_rfq_*` database with the existing real P25 approval, P29 owned source Draft, and P30 supplier/policy/publication APIs. It adds only finite P32 privileges on the 15 captured P32 tables, a mutable Draft-head UPDATE, and explicitly assigned synthetic Core action tokens. There is no worker or employee prerequisite. No business result is seeded.

`P32_HTTP_VERIFY_RFQ_COMMERCIAL_DRAFT=1` requires both `P29_HTTP_VERIFY_PRINCIPAL_RFQ=1` and `P30_HTTP_VERIFY_RFQ_PUBLICATION=1`. Between effective SOURCING policy publication and RFQ publication Open, the buyer sends a real PUT commercial Draft with a named evaluator and zero document requirements, repeats its exact key, sends a real POST Prepare and repeats that exact key. The tool independently reloads the Draft head and prepared plan under the finite Execution identity. P30 then publishes the same RFQ through its existing independent Core review. The final source reload requires one prepared plan and zero commercial round openings or submitted offers.

The accepted result code for this phase is `PASS_PRIVATE_P32_ZERO_DOCUMENT_PREPARED_CANDIDATE_ONLY`. It is **not** a full P32 review, supplier bid, evaluation, recommendation, award, or PO proof. `CommercialSubmitOffer` requires an original clean Core Document version and the typed policy requires `requireOriginalOfferDocument=true`; the tool deliberately does not invent one or call that endpoint. A later separate phase must create that document through actual Core ownership, scanning and use evidence, publish an independently reviewed `SOURCING_COMMERCIAL_ROUND` policy, and exercise round Open/Decide/SubmitOffer/Close/OpenOffers/assessment with separate owner readback. There is no P32 award endpoint.

No SDK compilation, PostgreSQL profile execution, browser request or production action is claimed by this source checkpoint. The tool-only compile and fresh native profile require independent review and physical readiness/finite grant proof.
