It requires the native approved competitive PR and publication/quote proof to finish first. The native RFQ reserves one of two approved units; the browser uses the remaining one.

It requires actual finite sourcing and publication readiness; a private identity header is rejected by normal local authentication. The new 0600 fixture is `/p25-evidence/p30-rfq-local-cookie-fixture.private.json`, schema 3, with buyer/reviewer IDs, native source/policy/case/shortlist IDs, a separate challenge and a 15-minute completion deadline. It does not contain an already accepted UI outcome. The normal HTTPS proxy uses existing prebuilt UI and preserves actual session cookies and browser headers, adding no identity or business mocks.

Before starting Playwright, run `verify_p30_rfq_cookie_owner.py capture` into a new protected baseline; `check-baseline` ensures it remains unchanged. After browser logout, run `verify` against the protected browser result and current private PostgreSQL owner store. Browser completion merely stops the listener. The owner verifier requires one additional published RFQ, independent Core case/decision, exactly two shortlisted suppliers, outside contact, a buyer-entered Draft quote, conserved approved demand, durable command receipts, no downstream PO/award/Finance rows, and revoked buyer/reviewer local sessions. The verifier is intentionally strict: missing or changed owning rows cause failure, with no automatic repair. Review its expected row graph against actual accepted P30 schema before execution.

The Playwright test is `reference-ui/tests/normal-cookie/p30-rfq-cookie.spec.ts`, config `playwright.p30-rfq-cookie.config.ts`, and proxy `scripts/p30-rfq-cookie-browser-proxy.mjs` on the isolated UI branch. It uses the original RFQ wizard, detail tabs and reviewer queue. Browser command bodies/keys are retained only in the protected 0600 result for independent owner verification. Screenshots, traces, video, request headers, cookies and passwords are not recorded. It never invokes dispatch, quotation submit, evaluation, award, PO or Finance actions.
